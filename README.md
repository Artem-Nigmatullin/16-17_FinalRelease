ゲームについて

このゲームは、時間内にコインを集めるゲームです。
プレイヤーはキャラクターを操作します。
ダメージを受けすぎないように注意します。

ゲームの流れ

ステージにコインがあります
制限時間内にコインを集めます

HPがなくなるとゲームオーバーです

敵について
敵の動きは、ゲームの状況で変わります。
コインを取る前は、おとなしい状態です
コインを取ると、プレイヤーを追いかけます

条件を満たすと、敵はいなくなります
コインエリアの仕組み
コインがあるエリアには、特別なルールがあります。

エフェクトがある時

エリアに入ると、コインが消えます
鍵を持った小さい敵が出ます
敵はプレイヤーから逃げます
プレイヤーは敵を追いかけて、鍵を取ります
鍵を使うと、コインが出てきます

エフェクトがない時

そのままコインを取れます

ポイント

タイミングが大切なゲームです
シンプルな操作で遊べます
プレイヤーの行動でゲームが変わります
