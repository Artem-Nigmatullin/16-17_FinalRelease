🔹 プロジェクト概要

本プロジェクトは、Unity（C#）を用いて制作した個人開発の3Dアクションゲームです。
制限時間内にコインを収集することを目的としたゲームとなっています。



プロジェクト内のスクリプトについて
本プロジェクトでは、ゲーム内の機能を制御するスクリプトは以下のフォルダに保存されています：
https://github.com/Artem-Nigmatullin/16-17_FinalRelease/tree/main/Assets/CoinGame/Scripts


技術構成

Unity（C#）
ステートパターンによる状態管理
敵AIの状態遷移制御
イベント駆動設計（コイン取得時の挙動変化）
エリア判定による特殊ルール実装
HP管理システム
制限時間タイマー制御

実装した主な機能
 敵AIの状態管理
通常状態（待機）
コイン取得後の追跡状態
条件達成後の消滅処理

状況に応じて挙動が変化する設計にしています。


コインエリアの特別ルール実装

特定エリアに入ると以下の処理が発生します：
コイン非表示処理
鍵を持つ敵の生成
逃走AIの実装
鍵取得後のコイン再出現
プレイヤー行動に応じたゲーム進行の分岐を実装しています。
